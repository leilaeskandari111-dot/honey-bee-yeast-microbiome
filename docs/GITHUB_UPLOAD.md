# GitHub upload checklist

## Recommended repository name

`honey-bee-yeast-microbiome`

## Recommended description

`Reproducible ITS bioinformatics and microbial-ecology analysis of the Apis mellifera hindgut mycobiome.`

## Visibility

Use **Public** if this is intended as a portfolio project for PhD applications.

## Before publishing

- Do not upload raw FASTQ files.
- Do not upload passwords, tokens, or API keys.
- Keep the `.gitignore` file.
- Keep the README as the first page visitors see.
- Keep the SRA accession and article DOI in the README.
- Keep the distinction between independently reproduced analyses and supplementary-data reanalysis explicit.

## Suggested first commit

`Initial honey bee ITS microbiome analysis`

## Suggested second commit

`Add raw-read QC and DADA2 workflow`

## Suggested GitHub topics

`bioinformatics`, `microbiome`, `microbial-ecology`, `honey-bee`, `amplicon-sequencing`, `ITS`, `DADA2`, `R`, `Python`

## Browser upload

GitHub supports creating a repository from the web UI and then using **Add file → Upload files** to upload an existing project. Browser uploads are limited to 25 MiB per file, so raw sequencing files should not be uploaded this way.
